# 一、项目背景

在嵌入式学习过程中，笔记本电脑的 USB 口往往很快被鼠标、键盘等设备占满，而嵌入式开发还需要通过 USB 连接主控进行烧录，可用接口严重不足。为此，我购买了一款市售的一拖三 USB-HUB（带一个 Micro-USB 接口），花了将近 30 块钱。

![市售 USB-HUB](https://upyun.luofish.com/blog/2026/03/2026-03-11-jKnNYM.jpg)

这款 HUB 的售价让我产生了一个疑问：**自己做一个到底需要多少钱？** 这个想法搁置了很久，寒假期间我终于决定动手实践。

---

# 二、方案选型

在开始设计之前，我调研了两种主流实现方案：

**方案一：MPU 类芯片方案**
需要编写固件，外围电路复杂，且性能对于简单 HUB 场景存在冗余，整体复杂度较高，不适合本项目。

**方案二：专用 USB-HUB 控制芯片方案（本项目采用）**
使用沁恒微电子的 CH344 系列芯片。该系列芯片高度集成，外围仅需少量阻容元件，单片价格低至约 1.4 元，性价比极高。

## 芯片型号选择

CH344 系列目前共有七种型号，针对本项目的应用场景，我重点对比了以下三款：

| 型号 | 说明 |
|------|------|
| CH335P | — |
| CH334P | — |
| **CH344P（本项目选用）** | 相较上述两款，额外支持 USB 状态指示灯功能 |

最终选择 **CH344P** 的原因：指示灯功能在后期调试阶段发挥了关键作用——通过观察 LED 状态，可以直观判断芯片是否成功退出复位并完成 USB 枚举，大幅降低了调试难度。

CH344P 主要规格如下（摘自数据手册）：
- 上行端口：支持 USB 2.0 高速（480 Mbps）及全速（12 Mbps）
- 下行端口：支持 USB 2.0 高速（480 Mbps）、全速（12 Mbps）及低速（1.5 Mbps）

# 三、硬件设计

## 3.1 原理图绘制

CH344P 的数据手册提供了详细的应用案例，可直接参照官方例程绘制原理图。以下为本项目最终的原理图：

![原理图](https://upyun.luofish.com/blog/2026/03/2026-03-11-V7gJmi.png)

几个关键设计说明：

**① 上行端口连接**
上行端口的 D+ 须连接至芯片的 DPU 引脚，D- 连接至 DMU 引脚，不可接反。

**② 晶振负载电容**
晶振须选择负载电容小于 **12 pF** 的型号，这一点极为关键。过大的负载电容会导致晶振无法起振，进而使整个系统无法正常工作。芯片内部已内置约 16 pF 的振荡电容，因此建议**不加外部振荡电容**。

**③ 热插拔防跌落处理**
下行端口在 USB 设备带电热插拔瞬间，动态负载可能导致 VBUS 和 5V 电压瞬时跌落，触发 LVR（低电压复位），表现为 HUB 反复断开重连。本项目通过将芯片 LDO 输出端电容增大至 **22 µF** 来改善这一问题。

**④ 过流保护**
采用低压降理想二极管芯片 CH213，提供简单的过流与短路保护功能。

**⑤ 电源设计**
CH344P 内置 3.3 V LDO，可直接由 5 V 供电输出 3.3 V，大幅简化了外围电源电路。

## 3.2 PCB 绘制

完成原理图后进行 PCB 布局布线，主要注意以下两点：

- **电源走线加粗**：5 V 主电源线需保证足够的载流能力；
- **差分对走线**：USB 数据线（D+/D-）须严格按照差分对规则走线，保持等长等距，且**不在中途换层打孔**。

# 四、焊接与调试

## 4.1 分步上电测试

焊接完电源部分（电容与理想二极管芯片）后，**先进行上电验证，再继续焊接其余元件**，可有效缩小问题排查范围。

**步骤一：验证下行端口 VBUS**
上电后用万用表测量各下行端口，确认 VBUS 电压正常输出 5 V。

![VBUS 测量](https://upyun.luofish.com/blog/2026/03/2026-03-11-DZoGU0.jpg)

**步骤二：验证 LDO 输出**
测量芯片 VDD33 引脚，确认 3.3 V 输出正常。

![VDD33 测量](https://upyun.luofish.com/blog/2026/03/2026-03-11-QQE18i.jpg)

电源部分验证通过后，再焊接晶振、主控芯片及其余元件。

## 4.2 踩坑记录：晶振负载电容问题

这是本项目遇到的最典型问题，也是整个调试过程中最耗时的部分。

**问题现象：**
初次焊接完成后上电，各点电压正常，但 LED 指示灯常亮（此状态表示芯片处于复位状态，尚未识别到下行设备）。将任意 USB 设备接入下行端口，电脑端仅显示「未知 USB 设备」，无法正常枚举。

**偶然发现的线索：**
使用万用表直流电压档测量晶振两端时，发现 LED 会短暂闪烁一下后熄灭，同时电脑端短暂识别到设备连接。

**原因分析：**
万用表电压档的探针自带约 100～200 pF 的寄生电容。将探针接触晶振引脚时，寄生电容无意中补充了缺失的负载电容，使晶振勉强起振，触发了一次不完整的 USB 枚举：
```
原始状态：负载电容 ≈ 11 pF（不足）→ 晶振无法起振 → 枚举失败 → LED 常亮

接触探针：负载电容 ≈ 11 pF + 探针寄生电容（~150 pF）→ 晶振勉强起振
    ↓
CH344P 尝试 USB 枚举 → LED 闪亮
    ↓
探针电容不稳定，时钟抖动严重 → 枚举通信出错
    ↓
电脑显示"未知 USB 设备" → 芯片复位重试
    ↓
反复失败 → LED 熄灭
```

这一现象证明了根因是**晶振负载电容选型错误**（原选用 20 pF 负载电容的型号，超出了芯片内置电容的匹配范围）。

**解决方案：**
更换为负载电容 **12 pF** 的晶振后，系统上电即正常工作，USB 枚举一次成功。

# 五、注意事项汇总

1. **晶振负载电容**：必须选择负载电容小于 16 pF 的型号（推荐 12 pF），否则系统无法正常运行；
2. **数据线选购**：购买 USB 连接线时务必确认为 **4 芯数据线**，勿购买仅 2 芯的充电线；
3. **主控芯片焊接**：CH344P 采用 QFN-16 封装，使用电烙铁焊接难度较大，**建议使用热风枪或加热台**配合锡膏进行回流焊接；

    ![QFN 封装焊接](https://upyun.luofish.com/blog/2026/03/2026-03-11-p7bTpG.png)

4. **导光柱**：LED 安装孔较小，不加导光柱时光线发散、亮度极低，建议选购直径 **2 mm 以内**的导光柱，截断后插入孔内即可获得柔和均匀的指示效果。

# 七、总结与收获

本项目是作者独立完成的第一个开源硬件项目，完整经历了从需求分析、方案选型、原理图设计、PCB 绘线、3D 外壳建模到实物焊接调试的全流程。

项目过程中最大的收获是学会了**如何根据数据手册系统性地定位和分析硬件问题**——晶振的踩坑让我深刻理解了负载电容对晶振起振的影响机制，这种通过现象推导根因的调试思路将会在今后的项目中持续受益。
